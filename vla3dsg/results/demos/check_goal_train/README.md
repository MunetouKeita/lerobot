# 学習用スイートの確認: vla3dsg_goal_train

- 日時: 2026-10-26〜28
- 目的: 追加学習のデモを作るスイート `custom_tasks/vla3dsg_goal_train/` で、配置・見え方・SG が意図どおりか、スクリプト制御（ランダム化あり）が成功するかを確かめる
- 実行: `uv run python vla3dsg/scripts/generate_demos.py --check --randomize --name demos/check_goal_train --suite vla3dsg_goal_train --task-ids 0 1 2 3 --n-episodes 10`

## シーン（各 50 の初期状態、最大 400 ステップ、指示文はすべて「Put the bowl on the plate」）

| task | 名前 | 配置 | 正解のボウル | 短い SG |
|---|---|---|---|---|
| 0 | wide | 見えるボウルを広い範囲（x −0.22〜0.16、y −0.10〜0.22）に置く。ほかは標準 | 見える（100%） | (black bowl, left of, wooden cabinet) |
| 1 | hidden | ボウルをワインラックの裏に置く（評価の `vla3dsg_goal` の hidden と同じ） | 隠れ（0%） | (black bowl, behind, wine rack) |
| 2 | hidden_decoy | 隠れた正解＋見えるおとりを広い範囲に置く | 隠れ（0%） | (black bowl 1, behind, wine rack) |
| 3 | decoy_visible | 見える正解を広い範囲に置く＋隠れたおとり | 見える（100%） | (black bowl 1, left of, wooden cabinet) など |

- 括弧内は、正解のボウルが agentview から見える点の割合（全 50 件の最小〜最大がこの値）
- 2 と 3 で指示文は同じため、どちらのボウルが正解かは SG を読まないと分からない（SG なしのモデルは 50% が上限）
- 広い範囲は皿・クリームチーズ・ワイン瓶・コンロと重なるため、`make_custom_task.py --min-distance 0.11` で、物体どうしが 11cm より近い配置、物がほかの物に乗った・触れた配置、評価と同じく読み込んで待つあいだに 2cm 以上動いた配置を除いた（除外は 1 タスクあたり約 200 件）
- 見えるボウルの位置（`positions.png`。赤が正解、灰色がおとり）は、ほかの物体を避けて 3 つのまとまりになる: ロボット寄りの中央（標準の位置の付近）、ロボット寄りの左、遠い左手前（公式の指示文で 0〜5% だった遠い位置）

## 掴む向き（`settings.DEMO_TASK_SPECS["vla3dsg_goal_train"]`）

見えるボウルは位置で掴める向きが違うため、ボウルの x で範囲を切り替える（`grasp_angles_by_x`）。16 か所 × 30° ごとに 1 回ずつ試して決めた（`tmp` の調査）。

| 位置 | 全か所で成功した角度 | 設定した範囲 |
|---|---|---|
| ロボット寄り（x < 0、8 か所） | 0〜150° | 0〜150° |
| 遠い左手前（x > 0、8 か所） | 180°（ロボット側の縁）のみ。150°・210° は 5/8 | 170〜190° |

隠れたボウルは `vla3dsg_goal` と同じ（75〜120°、手前を回る経由点）。
