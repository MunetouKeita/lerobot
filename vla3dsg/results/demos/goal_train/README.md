# 学習用デモの生成: goal_train（スイート vla3dsg_goal_train）

- 日時: 2026-10-28（このPC、52 分）
- 目的: 追加学習の教師データとして、学習用の 4 シーン（`custom_tasks/vla3dsg_goal_train/`、シーンの説明は `results/demos/check_goal_train/`）のデモを各 50 本、スクリプト制御（ランダム化あり）で作る
- 実行: `uv run python vla3dsg/scripts/generate_demos.py --name goal_train --suite vla3dsg_goal_train --task-ids 0 1 2 3 --n-episodes 50`、比較は `--report`
- データセット: `data/goal_train/`（git 管理外、302MB）。観測・動作は `lerobot/libero` と同じ形式。指示文はすべて「Put the bowl on the plate」。エピソード開始時の SG は `episodes.jsonl`
- 配置: 評価の初期状態とは別のシード（100000 から）でサンプリングし、評価の初期状態と同じ基準（`tasks.json` の `min_distance`: 近すぎる・乗った・触れた・待つあいだに動く配置）で除く

## 読み取れること

- 4 シーンとも 98% 以上の試行で成功し、各 50 本を作れた。広い範囲のシーンは配置の約 8 割が除かれる
- 見えるボウルのデモは公式の約 1.7 倍長く、移動の指令が小さい（上限に達しない）。手先が止まっている割合も少し多い。学習したモデルが公式より遅く動き、最大ステップ数に収まらない可能性がある（未検証）
- 隠れたボウルのデモ（約 310 ステップ）は、公式に対応するデモがない
