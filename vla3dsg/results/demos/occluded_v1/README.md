## スクリプト制御（`vla3dsg/demos/scripted.py`、タスクごとの設定は `settings.DEMO_TASK_SPECS["vla3dsg_occluded"]`）

- 今の高さのまま対象の真上へ水平に動き、下ろし、縁を掴み、持ち上げ、経由点を通って皿の上へ運び、放す
- 移動は 3 軸まとめた速さの上限 0.8・指令の変化量の上限 0.1、掴む・置く高さの 3cm 上からは速さ 0.3。回転は手先の向きを保つよう補正し、小さな揺らぎを加える。手先が止まったら次の動作へ進む
- 掴み方: 開いた指は初期の向きでは y 方向に並ぶ。縁の壁を指で挟むよう、次のようにした
  - task 0・2・3: ロボット側（x 方向）の縁を、手先を 90° 回して掴む
  - task 1: 電子レンジ側の指が壁に近すぎて掴み損ねる（39/50）ため、-y 側の縁を回さずに掴む（50/50）
- 経由点: task 0 は (−0.25, 0.0)、task 1 は (−0.28, 0.05) を通り、固定物を避ける
- 評価の初期状態での確認（`--check`、揺らぎなし）: task 0 46/50、task 1 50/50、task 2 48/50、task 3 50/50

この制御にした理由（2026-10-14〜15、古いスイート `vla3dsg_hidden` で作ったデモ v1・v2 で分かったこと。デモ自体は削除済み）:

- v1 は x 方向の縁を手先を回さずに掴もうとしたため、片方の指が縁に乗って下りられず、エピソードの約半分で押し続けていた（手先がほぼ止まっている割合 51%）。手先を回す・止まったら進む、に直して 6% になった
- v1 は 1 軸ずつ上限で動き、回転の指令が常に 0 だった。速さ・変化量の制限、向きの補正と揺らぎを加えた
- 斜めに下りながら近づくと背の高い固定物（電子レンジ）の角に当たることがあり、水平に動いてから下ろすようにした
