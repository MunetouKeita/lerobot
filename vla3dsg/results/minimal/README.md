## 結果

| 条件 | 成功率 | ボウル 1（正解）を置いた | ボウル 2（おとり）を置いた | 何も置かない・ほか |
|---|---|---|---|---|
| P1 SG から作った場所つきの指示文 | 94%（47/50） | 48 | 0 | 2 |
| P2 対象だけ（場所なし） | 84%（42/50） | 43 | 6 | 1 |
| P3 P2 ＋ 短い SG（1〜2 本） | 80%（40/50） | 40 | 3 | 7 |
| P4 P2 ＋ すべての SG（8〜10 本） | 68%（34/50） | 36 | 3 | 11 |
| P5 P2 ＋ 誤った SG（おとりの関係） | 80%（40/50） | 40 | 5 | 5 |

- 参考: 公式の指示文（実験1 の A）は 96%（48/50）
- Fisher の正確検定: P1 と P4 の差のみ有意（p = 0.002）。P1 と P2 は p = 0.20、P2 と P3 は p = 0.80、P3 と P4 は p = 0.25、P3 と P5 は p = 1.00、公式の指示文と P1 は p = 1.00
- 「ボウル 1 を置いた」の数は成功の数より 1〜2 多いことがある（皿の上にあるが、LIBERO の成功条件（中心のずれ 3cm 未満など）を満たさない）

- S3: どの条件でも、20 回中 2〜10 回、見えているおとりのボウルを皿に置いた。残りは何も置かずに時間切れ。隠れたボウルの方へ向かうことはない
- S4（おとりなし）: 隠れたボウルの代わりに、ボウルに似たラメキンを皿に置くことが 20 回中 4〜10 回あった

## 読み取れること

1. **SG の情報は、場所つきの自然な指示文にして渡すと使われる。三つ組で後ろに付けても使われない（標準のシーン）**
   - P1（SG から作った指示文）は 94% で、公式の指示文（96%）と同程度。おとりのボウルを置いたことは一度もない
   - P3（短い SG）は P2（場所なし）と同程度で、P5（誤った SG）とも同じ（どちらも 80%）。誤った SG でおとりを取る回数も増えない（3 回 → 5 回）。三つ組の内容は行動に反映されていない
   - P4（すべての SG）は 68% まで下がり、何も置かずに終わる失敗が増える（10 回）。SG が長いこと自体が動作を乱す
2. **新しいシーンでは、見えていても大きく失敗する**
   - S2 は 15〜35% で、標準のシーン（94%）から大きく下がった。電子レンジを加え物体を並べ直したシーンは、学習時のシーンと見た目が大きく違うためと考えられる（未検証）
   - そのため S3・S4 の 0% は、「隠れているから」と「見慣れないシーンだから」の両方が重なった結果で、追加学習なしの比較としては情報が少ない（どの条件も 0%）
3. **隠れていると、指示文や SG によらず、見えている似た物体を取りに行く**（おとりがあればおとり、なければラメキン）。hidden を伝えても変わらない

## 今後への示唆

- 追加学習では、SG を三つ組で付けるより、SG から場所つきの指示文を作って渡す（P1・P1h）形を主にするのがよい
- 新しいシーンは追加学習なしではほぼ動かないため、比較は追加学習ありで行う。学習データに新しいシーンの見える版（task 2・3）を含めることが必要
